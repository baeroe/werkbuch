# werkbuch

werkbuch is an open, self-hosted project management tool for teams: projects, work items with your own types, properties and workflows, a wiki per project, team-wide views across projects, recurring work items and switchable automations. It is built to be driven from the keyboard, and fully controllable over a REST API, an MCP server for AI agents and webhooks.

## Status

werkbuch is in development, in phase 9 of 15 (wiki): sign-in, the app shell, people and bots, tokens, roles and permissions, projects with members, the catalogs (workflows, types, properties, labels, relation types, resolutions), work items with relations and history, item lists with filters, saved views, board, table and timeline, search in the command palette and over REST, rich text with comments and attachments, notifications with mail and live updates, and the wiki per project are in place; templates, schedules and automations follow. There is no release yet, and these docs only cover what a contributor needs today. Running it locally is described on the [development page](/en/development); how roles, projects, workflows, types, work items, rich text, the wiki, views, notifications, search and bots work is under [Concepts](/en/concepts/permissions).
