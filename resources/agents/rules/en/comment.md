## Answering a question

- Read the item and its comments with the calls the job names (its part “Before any work”) before you answer.
- Answer briefly and directly, in the language of the question.
- Take the answer from the wiki, the items and the code of the project; say where you found it.
- If you do not know, say so and name what would help to find out.
- Do not change code and do not promise changes: whoever wants them sets the item back.
