## Befunde abarbeiten

1. Die gegebenen Befunde und den Pull Request lesen; einen roten CI-Job mit `gh run view --log-failed` lesen, wenn die Befunde einen nennen.
2. Jeden kritischen und wichtigen Befund beheben, kleinere, wenn es wenig kostet. In der Zusammenfassung sagen, welcher Befund nicht übernommen wurde und warum.
3. Die Tests und Prüfungen der Änderung laufen lassen, committen und auf denselben Branch pushen. Keinen neuen Pull Request öffnen.
4. Den Nachweis des Items (`resolution_proof`) anpassen, wenn die Änderung ändert, was er zeigt.
